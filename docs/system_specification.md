# Autonomous Spacecraft Guidance & Navigation
## System Specification

**Version:** 1.0  
**Status:** Initial project specification

---

## 1. System Purpose

The purpose of this project is to develop and evaluate a simulation of an
autonomous spacecraft guidance and navigation system.

The system shall estimate spacecraft state from imperfect measurements,
identify deviations from a desired trajectory, and generate corrective
control commands to reduce those deviations.

The project is intended to demonstrate a systems-engineering workflow
including requirements definition, functional decomposition, mathematical
modelling, simulation, verification, performance analysis, and engineering
trade studies.

---

## 2. System Boundary

### Included

- Two-dimensional spacecraft orbital dynamics
- Gravitational acceleration
- Numerical state propagation
- Simulated navigation measurements
- State estimation
- Reference trajectory definition
- Guidance calculations
- Control commands
- Closed-loop trajectory simulation
- Performance analysis
- Verification testing
- Trade-study analysis

### Excluded

- Real spacecraft hardware
- Real-time flight software
- Three-dimensional orbital mechanics
- Detailed spacecraft structural modelling
- High-fidelity atmospheric modelling
- Real spacecraft sensor hardware

## Navigation Subsystem

### Purpose

The navigation subsystem estimates the spacecraft state from simulated measurements that contain uncertainty.

The estimated state consists of spacecraft position and velocity:

$$
\hat{x} =
\begin{bmatrix}
\hat{x} & \hat{y} & \hat{v}_x & \hat{v}_y
\end{bmatrix}^T
$$

where the estimated state is distinguished from the true simulated state.

### Navigation Inputs

The navigation subsystem receives:

* simulated spacecraft measurements
* measurement uncertainty parameters
* simulation time

### Navigation Outputs

The navigation subsystem shall produce:

* estimated spacecraft position
* estimated spacecraft velocity
* position estimation error
* velocity estimation error

### Measurement Model

The initial navigation model will simulate measurements by adding noise to the true spacecraft state:

$$
z = x + \epsilon
$$

where:

* \(x\) is the true spacecraft state generated by the dynamics model
* \(z\) is the simulated measurement
* \(\epsilon\) represents measurement noise

The initial implementation will assume zero-mean Gaussian measurement noise. Noise levels will be configurable to allow performance testing under different measurement uncertainty conditions.

### Initial Navigation Assumptions

The initial navigation model will use:

* 2D spacecraft motion
* simulated measurements rather than real sensor data
* additive zero-mean Gaussian measurement noise
* configurable measurement noise magnitude
* the dynamics model as the source of the true spacecraft state

More realistic sensor models and additional sources of uncertainty may be introduced in later stages if they provide useful engineering value.

## 6. Performance Measures

The system will be evaluated using:

- Position-estimation error
- Velocity-estimation error
- Trajectory-tracking error
- Recovery following an initial trajectory deviation
- Control effort
- Robustness to measurement noise
- Computational runtime

Quantitative performance thresholds will be established following
initial baseline simulation results.

---

## 7. Verification Approach

Each requirement shall be mapped to one or more verification tests.

Verification methods will include:

- Numerical tests
- Analytical comparisons
- Scenario-based simulation
- Performance testing
- Stress testing

Test results shall be recorded as evidence against the corresponding
system requirement.

---

## 8. Key Assumptions

The initial model will assume:

- Two-dimensional motion
- A central gravitational field
- Constant gravitational parameter
- Point-mass spacecraft
- Simplified actuator behaviour
- Simplified navigation measurements
- No atmospheric drag
- No third-body gravitational effects

These assumptions may be relaxed in later project versions.

---

## 9. Success Criteria

The project will be considered successful when:

1. The spacecraft dynamics model produces physically consistent orbital
   trajectories.
2. Navigation estimates can be generated from noisy measurements.
3. Guidance and control can respond to trajectory deviations.
4. The integrated system demonstrates measurable trajectory correction.
5. Requirements can be verified using documented test cases.
6. Alternative approaches can be compared quantitatively.
7. Results and modelling assumptions are documented in a technical report.
